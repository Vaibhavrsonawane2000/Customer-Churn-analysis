# Customer-Churn-analysis
## Objectives
 To Analyzing customer churn using Python and Power BI, including data cleaning, EDA, predictive modeling, and business insights.
## Tools Used
- Python (Pandas, Seaborn)
- Machine Learning (Logistic Regression)
- Power BI

## Key Insights
- Month-to-month contracts have highest churn
- High monthly charges increase churn
- Electronic check users churn more

## Conclusion
Business should focus on long-term contracts and pricing strategies.

## Business Recommendations
- Promote long-term contracts
- Offer discounts for high monthly charges
- Encourage automatic payment methods
- Improve onboarding for new customers
